## 6. 현재 제출 원문과 실제 확인 코드의 대응 증거

`docs/REPRODUCTION_CODE_HASHES.json`에는 기준 커밋 `d72bb6f964399e239ddf4bd83845b45b3e773d28`에서 **Git blob 원문 바이트**로 읽은 `student/`, `src/`, `public/`, `tools/` 전체 및 `package.json`의 파일별 bytes·SHA256·Git blob ID가 있습니다. 이 목록은 현재 제출의 같은 경로와 대조할 수 있습니다. Windows CRLF 작업 폴더 변환으로 생기는 차이를 프로그램 변경이라고 잘못 세지 않도록 커밋 원문 기준입니다. 기록 보완 커밋들은 문서만 바꾸었고, 검수자가 `git diff <기준 커밋> HEAD -- student src public tools package.json` 결과가 비어 있음을 실제로 확인했습니다. JSON 자체는 문서 증거이며 실행 성공이나 백업 파일이 아닙니다.

기준 커밋과 기록 보완 커밋의 차이는 문서뿐이라는 주장을 확인할 수 있도록 실행 당시 실제 호출 순서는 `docs/REPRODUCTION_PROCEDURE.md`에 비밀·개인 경로를 제외해 남겼습니다. 새로운 실행 성공 기록을 만든 것이 아니며, 이 보완에서 동일 검사를 반복하지 않았습니다.

## 7. 제공 실행 코드의 버전 표기 차이

`package.json`의 시작 틀 배포 버전은 **0.2.15**입니다. 반면 현재 제공 `src/server.mjs`의 `meta().starterVersion` 및 `/api/diagnostics`의 `data.version`은 **0.1.0**이라는 고정 문자열입니다. 실제 진단 GET에서도 이 제공 버전 값을 반환하는 구조임을 원문과 대조했습니다. 이 둘을 같은 버전이라고 주장하거나 0.1.0이 최신이라고 판단하지 않습니다. 현재 제출 식별 기준은 **제출 Git 커밋 + package.json 0.2.15 + 파일별 원문 해시**입니다. 진단의 0.1.0은 이 제공 코드의 현존 표기 차이로 공개하며, 별도의 공식 버전 체계라고 임의로 정의하지 않습니다. 제공 서버를 학생이 수정하지 않는 범위를 지켜 이 표기 차이는 남아 있습니다. 버전 표시 정정은 제공자 후속 사항이며, 실제 연결·v1.0 인증이 완료됐다는 뜻이 아닙니다.
